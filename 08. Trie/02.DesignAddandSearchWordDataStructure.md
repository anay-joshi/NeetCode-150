# 211. Design Add and Search Words Data Structure

## 🧩 Problem

Design a data structure that supports:

- `addWord(word)` → Adds a word to the data structure
- `search(word)` → Returns true if the word matches any previously added word

### Special Rule

The search word may contain:

```
'.'
```

Which means:

```
match ANY single character
```

---

## 🔍 Example

```
addWord("bad")
addWord("dad")
addWord("mad")

search("pad") → false
search("bad") → true
search(".ad") → true
search("b..") → true
```

---

# 🧠 Core Idea

This is an extension of **Trie (Prefix Tree)**.

- Normal Trie → follows a single path
- With wildcard `.` → we must explore **multiple paths**

So we use:

> Trie + DFS (backtracking)

---

# 🏗 Data Structure

Each Trie node contains:

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26];
    boolean isEnd;
}
```

---

# ⚙️ Approach

## addWord(word)

- Insert characters into Trie
- Mark last node as `isEnd = true`

---

## search(word)

- Use DFS to traverse Trie
- Handle two cases:

### Case 1: Normal character

```
Follow the corresponding child node
```

### Case 2: Wildcard '.'

```
Try ALL possible children (branching)
```

---

# 💻 Java Implementation

```java
class WordDictionary {

    class TrieNode {
        TrieNode[] children = new TrieNode[26];
        boolean isEnd;
    }

    private TrieNode root;

    public WordDictionary() {
        root = new TrieNode();
    }

    public void addWord(String word) {
        TrieNode node = root;

        for (char c : word.toCharArray()) {
            int index = c - 'a';

            if (node.children[index] == null) {
                node.children[index] = new TrieNode();
            }

            node = node.children[index];
        }

        node.isEnd = true;
    }

    public boolean search(String word) {
        return dfs(word, 0, root);
    }

    private boolean dfs(String word, int pos, TrieNode node) {

        if (pos == word.length()) {
            return node.isEnd;
        }

        char c = word.charAt(pos);

        // Wildcard case
        if (c == '.') {
            for (TrieNode child : node.children) {
                if (child != null && dfs(word, pos + 1, child)) {
                    return true;
                }
            }
            return false;
        }

        // Normal character case
        int index = c - 'a';
        if (node.children[index] == null) {
            return false;
        }

        return dfs(word, pos + 1, node.children[index]);
    }
}
```

---

# 📊 Complexity Analysis

Let `L = length of word`

| Operation | Time Complexity |
|----------|----------------|
| addWord  | O(L) |
| search (no '.') | O(L) |
| search (with '.') | O(26^L) worst case |

Space complexity depends on total characters stored.

---

# 🧠 Key Insight

When encountering:

```
'.'
```

We must:

```
Explore ALL children nodes
```

This turns search into a **DFS (backtracking) problem**.

---

# 🎯 Pattern Recognition

This problem combines:

- Trie (prefix tree)
- DFS recursion
- Backtracking

---

# 🗣 Interview One-liner

> “I use a Trie for efficient word storage and perform DFS during search to handle wildcard characters.”

# ⚠️ Important Edge Cases
