# [17. Letter Combinations of a Phone Number](https://leetcode.com/problems/letter-combinations-of-a-phone-number/)
Medium


Given a string containing digits from 2-9 inclusive, return all possible letter combinations that the number could represent. Return the answer in any order.

A mapping of digit to letters (just like on the telephone buttons) is given below. Note that 1 does not map to any letters.



 

Example 1:
```
Input: digits = "23"
Output: ["ad","ae","af","bd","be","bf","cd","ce","cf"]
```
Example 2:
```
Input: digits = ""
Output: []
```
Example 3:
```
Input: digits = "2"
Output: ["a","b","c"]
 ```

Constraints:

- 0 <= digits.length <= 4
- digits[i] is a digit in the range ['2', '9'].

## 🔸 Approach
**Backtracking** — build combinations character by character.
At each digit → loop through mapped letters → recurse → undo.

---

## 🔸 Key Insights
- Every digit MUST contribute one letter → no "pick/not pick"
  → instead "which one to pick" (loop-driven backtracking)
- Base case: `idx == digits.length()` → add to result
- String → immutable → no undo needed
- StringBuilder → mutable → explicit undo required (`deleteCharAt`)

---

## 🔸 Backtracking Template (memorize this!)
```
for each choice:
    curr.append(c)                        // choose
    backtrack(idx + 1, curr, digits)      // explore
    curr.deleteCharAt(curr.length() - 1)  // undo
```

---

## 🔸 Two Flavors of Backtracking
| Pattern            | When to use              | Examples                  |
|--------------------|--------------------------|---------------------------|
| Pick / Not Pick    | Include or skip element  | Subsets, Subsequences     |
| Choice Among Options | Pick one from many     | This problem, Permutations|

---

## 🔸 String vs StringBuilder
| | String | StringBuilder |
|---|---|---|
| Mutability | Immutable | Mutable |
| New object per call? | ✅ Yes | ❌ No (reused) |
| Undo needed? | ❌ No | ✅ deleteCharAt |
| Memory | Less efficient | More efficient |

## 🔸 Final Code
```java
class Solution {

    Map<Character, char[]> mp;
    List<String> result;

    public List<String> letterCombinations(String digits) {
        result = new ArrayList<>();
        if (digits == null || digits.length() == 0) return result;

        mp = new HashMap<>();
        mp.put('2', new char[]{'a', 'b', 'c'});
        mp.put('3', new char[]{'d', 'e', 'f'});
        mp.put('4', new char[]{'g', 'h', 'i'});
        mp.put('5', new char[]{'j', 'k', 'l'});
        mp.put('6', new char[]{'m', 'n', 'o'});
        mp.put('7', new char[]{'p', 'q', 'r', 's'});
        mp.put('8', new char[]{'t', 'u', 'v'});
        mp.put('9', new char[]{'w', 'x', 'y', 'z'});

        backtrack(0, new StringBuilder(), digits);
        return result;
    }

    private void backtrack(int idx, StringBuilder curr, String digits) {
        if (idx == digits.length()) {
            result.add(curr.toString());
            return;
        }

        char[] letters = mp.get(digits.charAt(idx));

        for (char c : letters) {
            curr.append(c);                        // choose
            backtrack(idx + 1, curr, digits);      // explore
            curr.deleteCharAt(curr.length() - 1);  // undo
        }
    }
}
```

## 🔸 Complexity
| | Complexity |
|---|---|
| Time | O(4^n × n) → 4 is max letters per digit, n = digits length |
| Space | O(n) → recursion stack depth |

---

## 🔸 Edge Cases
| Case | Handling |
|---|---|
| Empty input `""` | Return empty list immediately |
| `null` input | Return empty list immediately |
| Single digit `"2"` | Returns `["a","b","c"]` |
| Digit `7` or `9` | Has 4 letters (pqrs / wxyz) — handled by map |

---

## 🔸 Pattern Used
> Backtracking → Choice Among Options (Loop-driven)

## 🔸 Interview One-Liner
> "For each digit, loop through its mapped letters, recurse for
> the next digit, and undo — classic loop-driven backtracking
> on a decision tree where every node must make exactly one choice."
