# [131. Palindrome Partitioning](https://leetcode.com/problems/palindrome-partitioning/)
Medium


Given a string s, partition s such that every substring of the partition is a palindrome. Return all possible palindrome partitioning of s.

A palindrome string is a string that reads the same backward as forward.

 

Example 1:
```
Input: s = "aab"
Output: [["a","a","b"],["aa","b"]]
```
Example 2:
```
Input: s = "a"
Output: [["a"]]
 ```

Constraints:

- 1 <= s.length <= 16
- s contains only lowercase English letters.


## 💡 Approach
**Backtracking** — At every index, try all possible substrings starting from `start`.  
If it's a palindrome → add to path → recurse → backtrack.

---

## 🔑 Key Insights
- When `start == s.length()` → valid partition found → save **copy** of path
- Try all `end` from `start` to `n-1` → covers all possible cuts
- Pass indices to `isPalindrome` instead of creating new substring → avoids extra memory
- Always save `new ArrayList<>(path)` → not `path` directly **(reference trap)**
- **3-line backtracking heartbeat** (memorize this):
```
CHOOSE   → path.add(...)
EXPLORE  → backtrack(...)
UNCHOOSE → path.remove(...)
```

---

## 🧠 Mental Model
> Think of it as a decision tree — at each node you pick a cut,
> check if it's a palindrome, go deeper, then **erase and try next cut.**

---

## ✅ Java Code
```java
class Solution {
    public List<List<String>> partition(String s) {
        List<List<String>> result = new ArrayList<>();
        List<String> path = new ArrayList<>();
        backtrack(s, 0, path, result);
        return result;
    }

    private void backtrack(String s, int start, List<String> path, List<List<String>> result) {
        if (start == s.length()) {
            result.add(new ArrayList<>(path));  // save a COPY
            return;
        }

        for (int end = start; end < s.length(); end++) {
            if (isPalindrome(s, start, end)) {
                path.add(s.substring(start, end + 1));   // CHOOSE
                backtrack(s, end + 1, path, result);      // EXPLORE
                path.remove(path.size() - 1);             // UNCHOOSE
            }
        }
    }

    private boolean isPalindrome(String s, int start, int end) {
        while (start < end) {
            if (s.charAt(start++) != s.charAt(end--)) return false;
        }
        return true;
    }
}
```

## 📊 Complexity

| | Complexity | Reason |
|---|---|---|
| **Time** | O(N · 2^N) | 2^N possible partitions, O(N) to check each palindrome |
| **Space** | O(N) | recursion stack depth + path list |

## 🔁 Patterns Used
- Backtracking
- Decision Tree
- Two Pointer (inside isPalindrome)

---

## 🗣️ Interview One-Liner
> *"I use backtracking — at each index I try all possible cuts, recurse if the substring is a palindrome, and backtrack by removing the last element from the path."*

---

## ⚠️ Edge Cases
| Case | Behavior |
|------|----------|
| Single character `"a"` | Returns `[["a"]]` — always a palindrome |
| All same characters `"aaa"` | Multiple valid partitions — `[["a","a","a"], ["a","aa"], ["aa","a"], ["aaa"]]` |
| Already a palindrome `"aba"` | Both `["a","b","a"]` and `["aba"]` are valid |
| Two characters `"ab"` | Only `["a","b"]` — `"ab"` is not a palindrome |
