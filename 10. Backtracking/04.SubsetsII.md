# [90. Subsets II](https://leetcode.com/problems/subsets-ii/)
Medium


Given an integer array nums that may contain duplicates, return all possible subsets (the power set).

The solution set must not contain duplicate subsets. Return the solution in any order.

 

Example 1:
```
Input: nums = [1,2,2]
Output: [[],[1],[1,2],[1,2,2],[2],[2,2]]
```
Example 2:
```
Input: nums = [0]
Output: [[],[0]]
 ```

Constraints:

- 1 <= nums.length <= 10
- -10 <= nums[i] <= 10

## 🔑 Core Idea

At each index, we have 2 choices:

```
1. PICK the element
2. NOT PICK the element
```

But because duplicates exist, we must **avoid generating duplicate subsets**.

---

## 🧠 Key Strategy

### 1️⃣ Sort the array

```java
Arrays.sort(nums);
```

- Groups duplicates together
- Makes skipping easier

---

### 2️⃣ Use Pick / Not-Pick recursion

- PICK → include element
- NOT PICK → skip ALL duplicates of that element

---

## ⚙️ Algorithm

### Base Case

```java
if (idx == nums.length)
```

- Subset complete → add to result

---

### Recursive Steps

#### 1️⃣ PICK

```java
temp.add(nums[idx]);
backtrack(nums, idx + 1, res, temp);
temp.remove(temp.size() - 1);
```

- Include current element
- Move forward

---

#### 2️⃣ SKIP DUPLICATES (Important)

```java
int next = idx;
while (next + 1 < nums.length && nums[next] == nums[next + 1]) {
    next++;
}
```

- Skip all duplicate occurrences

---

#### 3️⃣ NOT PICK

```java
backtrack(nums, next + 1, res, temp);
```

- Move to next distinct element

---

## 💻 Java Implementation

```java
class Solution {
    public List<List<Integer>> subsetsWithDup(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        List<Integer> temp = new ArrayList<>();
        Arrays.sort(nums);
        backtrack(nums, 0, res, temp);
        return res;
    }

    private void backtrack(int[] nums, int idx,
                           List<List<Integer>> res,
                           List<Integer> temp) {

        if (idx > nums.length) {
            return;
        }

        if (idx == nums.length) {
            res.add(new ArrayList<>(temp));
            return;
        }

        // PICK
        temp.add(nums[idx]);
        backtrack(nums, idx + 1, res, temp);
        temp.remove(temp.size() - 1);

        // SKIP duplicates
        int next = idx;
        while (next + 1 < nums.length && nums[next] == nums[next + 1]) {
            next++;
        }

        // NOT PICK
        backtrack(nums, next + 1, res, temp);
    }
}
```

```
Pick → include first 2
Not Pick → skip ALL 2s → jump to next distinct
```

## ⚠️ Important Points

### 1️⃣ Why skip duplicates?

Without skipping:

```
[2] appears multiple times
[1,2] appears multiple times
```

---

### 2️⃣ Why skip only in NOT PICK?

```
Pick branch → allows duplicates in subset (valid)
Not Pick → must skip duplicates to avoid repetition
```

---

### 3️⃣ Why use `next` instead of modifying `idx`?

- Avoids mutating recursion parameter
- Keeps recursion predictable and clean
